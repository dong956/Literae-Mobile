安装与导入

当前设备

按浏览器完成安装

    iPhone / iPad · Safari
    1. 用 Safari 打开 Literae Mobile 页面。
    2. 轻点工具栏中的“分享”按钮；如果只看到“更多”，先点“更多”，再点“共享”。
    3. 在操作列表向下滑，选择“添加到主屏幕”。若没有该项，滑到底部点“编辑操作”，把它加入列表。
    4. 确认开启“作为网页 App 打开”，轻点右上角“添加”。以后从主屏幕上的 Literae Mobile 图标进入。
    iPhone / iPad · Chrome
    1. 用 Chrome 打开 Literae Mobile 页面。
    2. 轻点地址栏右侧的“分享”按钮。
    3. 选择“添加到主屏幕”，确认名称后轻点“添加”。
    4. 回到主屏幕，轻点 Literae Mobile 图标进入。
    Android · Chrome
    1. 用 Chrome 打开 Literae Mobile 页面。
    2. 轻点地址栏右侧的“⋮”菜单。
    3. 选择“添加到主屏幕”，再点“安装”；部分版本会直接显示“安装应用”。
    4. 按屏幕提示确认，安装后从桌面上的 Literae Mobile 图标进入。

    导入桌面文库

    1. 在 Mac 上打开 Literae：设置 → 移动端 → 生成数据包 → 下载 ZIP。
    2. 将 ZIP 隔空投送到 iPhone/iPad 的“文件”App，或传到 Android 的“下载”目录；不要解压。
    3. 回到 Literae Mobile，点“选择数据包”，选中 ZIP。导入完成后即可使用书库、书内检索和全库检索。

    数据导入后保存在本机。更换浏览器、清除网站数据或卸载网页 App 前，请保留原 ZIP 以便重新导入。
